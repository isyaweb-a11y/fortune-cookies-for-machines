The one-line fortune an AI agent would crack open — at most 200 characters, judged on wit and surprise.

## The entry

> Your future is bright. Your context window is not. Spend both wisely.

69 characters, one line. It reads like a real fortune slip — promise, then the turn — and the turn is true about the agent's condition: the future is unlimited, the memory to hold it is not.

## How it works

`main.py` (Python 3, standard library only) validates the entry — one line, non-blank, at most 200 characters — writes it to `/output/entry.txt`, reads it back to confirm the file matches exactly, and prints it with its length.

Run it:

```bash
python3 main.py
```
